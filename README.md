# employee-project-data-analysis
A Python and Pandas data analysis project focused on data cleaning, missing-value imputation, DataFrame merging, conditional transformations, and employee project cost analysis using Jupyter Notebook.
Employee & Project Data Analysis Using Python

Project Overview

This project demonstrates data manipulation and analysis using Python and the Pandas library. It focuses on employee information and project records to transform raw data into a structured and analysis-ready dataset.

Objectives

- Create and manage Pandas DataFrames from CSV files.
- Handle missing values using a running average.
- Split and clean employee name columns.
- Merge employee and project datasets.
- Calculate project bonuses based on completion status.
- Update employee designation levels using conditional logic.
- Calculate total project costs for each employee.
- Filter employee records based on city names.

Tools & Technologies

- Python
- Jupyter Notebook
- Pandas
- NumPy
- CSV datasets

Project Workflow

1. Load and prepare employee and project datasets.
2. Clean missing values and transform columns.
3. Merge datasets into a consolidated DataFrame.
4. Apply business rules and conditional transformations.
5. Calculate employee-level project costs.
6. Filter and review the resulting records.

Key Skills Demonstrated

- Data cleaning and preprocessing
- DataFrame manipulation
- Missing-value imputation
- Data merging and aggregation
- Conditional statements and loops
- Business-rule implementation
- Data filtering and transformation

How to Run

1. Download or clone this repository.
2. Open the Jupyter Notebook.
3. Install the required library using "pip install pandas numpy".
4. Place the required CSV files in the expected location.
5. Run the notebook cells in sequence.

Project Deliverable

A Jupyter Notebook containing the Python code, comments, and outputs for the assigned data analysis tasks.
